Report 008 — Architecture Ablation

Ego-Conditioned Pedestrian Motion · Is the paper's "cross-attention" actually better? · 2026-07-17
Bottom line: The paper describes a cross-attention (trans_dec) denoiser, but a config-merge bug meant the reported model is actually a self-attention encoder (trans_enc). I trained the real cross-attention model to settle whether the intended architecture is better. At matched batch size, the two are statistically indistinguishable — cross-attention gives no benefit. The real result (full-sequence conditioning ≫ pooled) stands; only the mechanism description needs fixing.

trans_enc 3.338 vs trans_dec 3.490 at matched batch 128: 95% CIs overlap ([3.15, 3.53] vs [3.43, 3.55]) → the 0.15 gap is not statistically significant. The batch size explained most of the earlier bs64 gap (3.725 → 3.490).

What we learned

  • Cross-attention is not the source of the win. At matched batch it ties (marginally loses to) the accidental self-attention model, and it trains less stably (FID bounced 3.5–4.8 across epochs vs trans_enc's smooth curve).
  • The real driver is full-sequence conditioning. Both architectures feed the denoiser all 196 per-timestep ego tokens and land at ~3.3–3.5 FID; the pooled single-token baseline (H2) is stuck at 6.6. The 49% improvement is about temporal granularity of conditioning, not the attention mechanism.
  • trans_enc has slightly better conditioning alignment (R@1 0.537 vs 0.501); trans_dec generates slightly more diverse motion per condition (MM 4.61 vs 4.14).

Recommended paper fix

  • Correct the mechanism. Rewrite §Method (Diffusion Denoiser), Fig 1, and the Abstract to describe the actual model: self-attention over the concatenated [latent, time, full-ego-sequence] token set. Drop the "cross-attention makes it affordable (O(L·T) vs O((L+T)²))" argument — the model pays the O((L+T)²) cost and it's fine at this scale.
  • Reframe the contribution as full-sequence vs pooled temporal conditioning (architecture-agnostic).
  • Turn the bug into a strength: add this trans_dec vs trans_enc comparison as an ablation — "cross-attention is not required; self-attention over the concatenated ego sequence is comparable."

All headline numbers (FID ~3.3–3.5, 49% over pooled, H6 rejection, held-out generalization) remain valid. This is a description fix + a bonus ablation, not a result retraction.

Method notes (reproducibility)

  • Config-merge bug: configs/modules/denoiser.yaml (arch: trans_enc) overrode the H4 config's arch: trans_dec. Correct override is model.denoiser.params.arch=trans_dec.
  • trans_dec trained locally on an RTX 4090, same recipe as H4 (frozen VAE + frozen ego encoder, same data); effective batch 128 via gradient accumulation (micro 64 × 2), env-driven ACCUM_GRAD_BATCHES added to train.py.
  • Held-out test set: scene-disjoint split of val (no reserve data existed) → val_test (1,190) / val_sel (1,140).
